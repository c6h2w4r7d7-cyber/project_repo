# RunComfy AI

**Problem:** Runners who want to run somewhere new in Switzerland do not know which route suits them: how long it is, how hilly it is, and whether the weather and air are good right now.

**Solution:** RunComfy suggests up to three closed running loops from any Swiss starting point. It scores them against your preferences and the current conditions. A machine-learning model trained on your own past runs estimates how long each loop will take you. Every loop can be downloaded as a GPX file.

## Run the app

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

No API keys are needed. The page has two tabs:

- **Find a route:** search a Swiss location or click the map to set the start, choose your preferences and click **Find running routes**. The three best loops appear on the map and as cards below it, each with a GPX download.
- **My running log:** log your past runs. The machine-learning model learns your pace from them and shows how accurate it is.

## Fitness level and elevation preference

**Fitness level:** how often, how far and how fast you usually run. It does two things:

- **First time estimate:** pace × (distance + climbing / 100 m), like the Swiss "Leistungskilometer": 100 m uphill take about as long as one extra km on the flat. Once you have logged 3 runs, your personal machine-learning model takes over.
- **Distance hint:** if the chosen distance is longer than recommended for your level, a hint appears below the distance slider.

| Fitness level | Who is this? | Pace | Hint above |
|---|---|---|---|
| Beginner | You run now and then, usually up to 5 km. | about 7 min per km | 8 km |
| Intermediate | You run every week, usually 5–10 km. | about 6 min per km | 15 km |
| Advanced | You train several times a week, often more than 10 km. | about 5 min per km | no hint |

**Elevation preference:** metres uphill per km of the route, the same for everyone. Because it is per km, a level means the same for every distance. The app also shows the total for the chosen distance, e.g. Flat on 5 km means 0–50 m uphill.

| Elevation preference | Meaning | Climbing |
|---|---|---|
| Flat | Hardly any hills | 0–10 m per km |
| Moderate | Some short climbs | 10–25 m per km |
| Hilly | Many climbs | 25–50 m per km |

A route inside the range gets the full 30 elevation points. Every m per km outside the range costs one point and causes a warning. All values are in `settings.py`.

## Data sources and libraries

- **swisstopo / GeoAdmin API:** map tiles, location search, Swiss border check and elevation profiles. [Documentation](https://docs.geo.admin.ch/)
- **Valhalla routing** (public FOSSGIS demo server) with **OpenStreetMap** data, © OpenStreetMap contributors. [Valhalla](https://valhalla.github.io/valhalla/)
- **Open-Meteo:** weather and air quality. [open-meteo.com](https://open-meteo.com/)
- **OpenLayers:** map display in the browser. [openlayers.org](https://openlayers.org/)
- Python libraries: Streamlit, requests, pandas, scikit-learn, shapely, pyproj.

The public Valhalla server is meant for development and light use: it accepts one request per second, so a route search takes about 10 seconds.

**Demo data:** `runs.csv` contains 18 invented runs for the runner "Julian". They are there to demonstrate the model in the presentation.
